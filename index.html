How I work

From raw file to decision

Every project follows the same five steps, so nothing is guessed and every number can be traced back to its source.

1

Audit

Check sources, data types, duplicates and gaps before touching a chart.

2

Clean

Standardize names, dates and categories, and document every change.

3

Model

Build clean relationships: a star schema in Power BI or structured tables for pivots.

4

Measure

Define each KPI once as a DAX measure or formula, so every number matches.

5

Deliver

A dashboard your team can read in seconds, with notes on how to maintain it.
